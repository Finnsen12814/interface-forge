# Interface Forge

Research-led UI/UX for Codex and Claude. The skill helps an agent research, specify, implement, redesign, and audit production interfaces for websites and Electron apps without collapsing into a generic component-library aesthetic.

## Install

Copy this repository to one or both locations:

```text
Codex:  ~/.codex/skills/interface-forge
Claude: ~/.claude/skills/interface-forge
```

Reload the client, then invoke `$interface-forge` or request UI/UX design, implementation, or review work.

`SKILL.md` routes the workflow; `references/` provides focused playbooks; `scripts/check_skill.py` checks reference integrity; `agents/openai.yaml` supplies Codex metadata. Linked sources are research references, not bundled dependencies or assets.
